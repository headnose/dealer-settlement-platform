Settlement desk (basic UI, local practice)

Import closed loans, calculate settlements, generate and send wires. Every call and its raw answer is shown on the right.

Who you are

Locally there is no ALB, so paste the signed header it would send. From the repository root (valid 60 min): java dev-tools/AlbDevToken.java dev-finops FinanceOps 60 and java dev-tools/AlbDevToken.java dev-admin SettlementAdmin 60.

1. Loans

Look a loan up in loan-service, then import one or more into settlement-service. Demo loans LN-5001 to LN-5200 are all CLOSED; each loan can be sent only once.

2. Settlement

Gross comes from the imported principal. Add adjustments, predict the net, then calculate.

Adjustment typeAmount
Load the principal to see the expected net.

3. Wire

Generate a DRAFT wire as FinanceOps, then send it as SettlementAdmin (maker-checker). Emails arrive in Mailpit: localhost:8025.

Calls

Method, path, status and the raw JSON answer, newest first. Errors are RFC 9457 problem details from the services.
